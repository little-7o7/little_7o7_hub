# little_7o7_hub — программа Little Hub (правила для Claude)

Программа владельца little_7o7 для его компьютеров (офис, дом, Mac): копии хаба и проектов по дням на своих дисках
и курсы валют с узбекских сайтов для хаба. Хаб — репозиторий `little-7o7/little_7o7` (`src/app/api/pc`,
`src/lib/pc*.ts`, `src/lib/fx*.ts`), его правила главнее. План: `little_7o7/.claude/plans/pc-backup-1.plan.md`.

## Язык

- Ответы, комментарии, тексты окна — по-русски (окно ещё и по-английски). Коммиты — conventional-тип + описание
  по-русски (`feat: копия хаба по дням`).

## Как работаем

- Новая функция — сначала план в хабе (`little_7o7/.claude/plans/`), код — после «да» владельца.
- TDD: сначала тест; `go test ./...`, `go vet ./...`, `GOOS=windows go vet ./...`, `gofmt -l .` — пусто.
- После кода — ревью кода и безопасности (ключ компьютера, окно на 127.0.0.1, обновление, копии).

## Устройство

- `cmd/littlehub` — запуск, `--install`, `--uninstall`, `--self-test`.
- `internal/app` — работа: флаг хаба раз в 2 минуты, копия после 2 минут затишья (не дольше 15), курсы раз в 3 часа,
  обновление раз в 6 часов. `internal/days` — файл дня по Ташкенту, `internal/disks` — диски по порядку.
- `internal/hub` — запросы к хабу (`/api/pc/*`), ключ компьютера — только хабу. `internal/secret` — ключ под DPAPI
  (Windows) или в «Связке ключей» (Mac). `internal/ui` — окно: Host только 127.0.0.1/localhost, cookie, X-LH.
- `internal/copyfmt` — формат копий `L7-DB-1` и `SARPO-DB-1`; образцы в `testdata` сделаны кодом хаба.
- `internal/rates` — только свой список адресов (cbu.uz, nbu.uz, bank.uz); разбирает хаб.

## Выпуск

- Текст выпуска — `releases/vX.Y.Z.md` (сначала по-русски, потом «What's new» по-английски), потом Actions → build →
  Run workflow с `version` = `X.Y.Z` (из облачной сессии тег не отправить — прокси обрывает; запуск — через GitHub
  API). GitHub Actions создаёт тег и выпуск, собирает Windows и Mac, кладёт SHA256SUMS; Mac не собрался — выпуск
  выходит с Windows. Тег `vX.Y.Z`, отправленный вручную, работает так же. Программы на компьютерах обновятся сами.
- Telegram — только ботом хаба (владелец 2026-11-08): программа сама в Telegram не пишет.
- Секреты — никогда в git. Ключа подписи обновлений пока нет (подпись ed25519 отложена).
