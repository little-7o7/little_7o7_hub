Little Hub 1.4.0 — подписанные обновления и сборка копии из частей

- Обновление ставится только с верной подписью владельца (ECDSA P-256): даже если кто-то подменит файл выпуска и его SHA-256 на хабе или в GitHub, программа такое обновление не скачает и не запустит. В журнале — «обновление … без верной подписи — не ставлю».
- «Файлы» → «Собрать копию из частей»: копии больше 50 МБ хаб присылает в Telegram частями по 45 МБ (…l7copy.part1-of-3 и т. д.). Сохраните все части в одну папку, укажите путь к любой — программа склеит копию рядом и покажет её SHA-256 (сверьте с подписью последней части в Telegram). Дальше — «Расшифровать копию», как обычно.
- Команда установки в README — с адреса little7o7.com.

What's new

- Updates install only with the owner's valid signature (ECDSA P-256): even if someone swaps a release file and its SHA-256 on the hub or GitHub, the program will not download or run it. The log says "update … without a valid signature — not installing".
- "Files" → "Join copy from parts": copies over 50 MB come to Telegram in 45 MB parts (…l7copy.part1-of-3 etc.). Save all parts into one folder and point to any of them — the program joins the copy next to them and shows its SHA-256 (compare with the caption of the last part). Then "Decrypt copy" as usual.
- The install command in the README now uses little7o7.com.
