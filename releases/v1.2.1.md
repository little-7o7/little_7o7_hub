Little Hub 1.2.1 — файлы Strassio, кнопка «Обновить программу» и ярлыки

- Strassio: на диске в папке «Little Hub\Strassio» — «Ключи.xlsx», «Клиенты.xlsx», «Оплаты.xlsx» и папка «Клиенты» с папкой на каждого клиента: «Всё о клиенте.xlsx» (о клиенте, ключи, компьютеры, договоры, начисления, долги, заявки) и файлы договоров (PDF, сканы). Клиента больше нет — его папка уходит в «Клиенты (архив)».
- Кнопка «Обновить программу» в окне Little Hub (карточка «Программа») и в хабе (Настройки → Компьютеры): программа проверяет и ставит новую версию сразу, закрывать и открывать её больше не нужно. По кнопке из хаба обновляются все компьютеры за 2 минуты.
- Кнопка «Открыть папку» (в «Файлах проектов» и у каждого диска): открывает «Little Hub» на диске в Проводнике или Finder. В окне видно, в какой папке лежат файлы.
- Windows: ярлык «Little Hub» в меню «Пуск» и на рабочем столе. После «Выход» программу открывают им; если она уже работает, ярлык откроет её окно.
- Установленные программы обновятся сами.

What's new
- Strassio: on the disk, in “Little Hub\Strassio” — “Ключи.xlsx” (keys), “Клиенты.xlsx” (clients), “Оплаты.xlsx” (payments) and a “Клиенты” folder with one folder per client: “Всё о клиенте.xlsx” (client info, keys, computers, contracts, charges, debts, requests) and contract files (PDF, scans). A client gone from the list — their folder moves to “Клиенты (архив)”.
- An “Update the program” button in the Little Hub window (the “Program” card) and in the hub (Settings → Computers): the program checks for and installs a new version right away, no need to quit and start it again. The hub button updates all computers within 2 minutes.
- An “Open folder” button (in “Project files” and next to each disk): opens “Little Hub” on the disk in Explorer or Finder. The window shows which folder holds the files.
- Windows: a “Little Hub” shortcut in the Start menu and on the desktop. After “Quit”, start the program with it; if it is already running, the shortcut opens its window.
- Installed programs update themselves.
