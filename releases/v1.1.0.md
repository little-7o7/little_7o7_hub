Little Hub 1.1.0 — установщик для Windows

- Установщик: хаб → Настройки → Компьютеры → «Добавить компьютер» → «Скачать установщик». Откройте LittleHub-Setup.exe — программа поставится и подключится к хабу сама, без PowerShell. Код подключения уже внутри файла (10 минут).
- Код устарел — программа всё равно ставится, а в её окне можно ввести новый код.
- Установленные программы 1.0.0 обновятся сами.

What's new
- Installer: hub → Settings → Computers → “Add computer” → “Download installer”. Open LittleHub-Setup.exe — the program installs and connects to the hub by itself, no PowerShell. The connection code is inside the file (10 minutes).
- If the code has expired, the program still installs, and a new code can be typed in its window.
- Installed 1.0.0 programs update themselves.
