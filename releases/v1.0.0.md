Little Hub 1.0.0 — первая версия

Программа хаба little_7o7 для компьютеров владельца (Windows и Mac).
- Каждый день — копия базы хаба на диск компьютера: один файл на день, до 00:00 по Ташкенту он обновляется, потом остаётся как есть. Копия зашифрована паролем копий из хаба.
- При запуске сразу берёт последнее состояние хаба; дальше — после изменений в хабе (не чаще раза в 15 минут).
- Диски для копий выбираются в окне программы; можно добавить новый жёсткий диск.
- Курсы валют: раз в 3 часа берёт курс ЦБ Узбекистана и курсы узбекских банков и отправляет хабу, хаб рассылает их проектам.
- Значок у часов, окно программы в браузере, русский и английский.
- Обновляется сама: новая версия проверяется по SHA-256, не запустилась — возвращается прежняя.

What's new
The little_7o7 hub program for the owner's computers (Windows and Mac).
- A daily copy of the hub database on the computer's disk: one file per day, updated until 00:00 Tashkent time, then kept as is. The copy is encrypted with the hub's backup password.
- Takes the latest hub state at start-up, then after hub changes (at most every 15 minutes).
- Backup disks are chosen in the program window; a new hard drive can be added.
- Exchange rates: every 3 hours it takes the Central Bank of Uzbekistan rate and Uzbek bank rates and sends them to the hub, which passes them to the projects.
- Tray icon, program window in the browser, Russian and English.
- Updates itself: a new version is checked by SHA-256; if it does not start, the previous one comes back.
